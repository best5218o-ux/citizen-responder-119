# 구급차보다 먼저 닿는 손 — 「119 시민응답자」 호출체계 시제품

제1회 소방정책 아이디어 발굴 경진대회(한국소방단체총연합회) 본선 출품 · 팀 브랜드 AI (김영민 · 정병진)

**바로 실행:** https://best5218o-ux.github.io/citizen-responder-119/  ·  **시연 영상:** [demo.mp4](demo.mp4) (48초)

## 화면
1. **119 상황실** — 심정지 의심 신고 → AI 도착지연 예측(6분 내 미도착 확률) → 기준 초과 시 반경 500m 시민응답자 2명 호출(CPR 직행 / AED 확보) → 처리 경과
2. **시민응답자 앱** — 호출 알림 수락 → 역할 배정 → AED 보관함 일회용 해제 번호 → 가슴압박 박자 안내 → 인계 후 위치정보 파기·안부 연락
3. **구급 공백 대시보드** — 시도별 구급대 10분 초과 도착 비율과 심정지 추정 규모

## AI 도착지연 예측 모델
- 학습 데이터: 소방청 「전국 구급 현황」(소방안전 빅데이터 플랫폼) 2025년 1월 초 출동 12,336건 (전처리 후)
- 목표: 출동 → 현장 도착 6분 초과 여부
- 입력: 시도, 도시/농촌, 시간대, 현장 거리
- 모델: 로지스틱 회귀 (`model/train.py`, 계수 `model/model.json`)
- 검증(30% 분리): AUC 0.80, 심정지 출동만 AUC 0.80 (124건)

## 한계
- 응답자·AED 위치와 처리 경과 시간은 시연용 가상 시나리오입니다. 구급차 이동은 평균 시속 40km, 응답자 이동은 분당 150m로 가정했습니다.
- 학습 표본은 연초 단기 자료입니다. 시범사업 단계에서 연간 전체 자료로 다시 학습합니다.
